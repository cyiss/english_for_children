# 儿童英语182天学习计划

每天30分钟，26周共182天。包含词汇、自然拼读、原创短文、对话、参考答案、阶段检测和每日打卡。

## GitHub Pages

在仓库 Settings → Pages 中选择 Deploy from a branch，分支选择 `main`，目录选择 `/ (root)`，保存。

预计网站地址：https://cyiss.github.io/english_for_children/

语音使用设备的英语声音；打卡保存在浏览器本地，可导出备份，不支持跨设备自动同步。

下载文件：`manual.pdf`、`manual.docx`、`learning-pack.zip`。
